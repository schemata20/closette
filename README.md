# Closette

Website Closette oleh Schemata Works.

HTML, CSS dan JavaScript tanpa React.

https://shopclosette.com/

## Checkout upgrade

The original design is retained. Checkout, Billplz integration, D1 order records, transactional email and an admin dashboard are implemented on the commerce branch. Online payment is disabled until the merchant accounts and backend are configured.

Read [DEPLOYMENT.md](DEPLOYMENT.md) for setup, acceptance tests, secrets and the safe hosting cutover. GitHub stores the source; the commerce application deploys to Cloudflare Workers with Static Assets.
